# 科学实现

实现按学科与共享依赖组织，导入和运行由工具执行器按需触发。INDEX.md由build_catalog命令从当前绑定自动生成。公开工具名与Python函数名不必相同；准确绑定、输入输出和环境要求以[工具契约](../catalog/catalog.json)为准。[逐模块实现索引](INDEX.md)列出每个文件绑定的公开工具及辅助模块用途。

| 目录／文件 | 内容 |
| --- | --- |
| chemistry/ | 分子结构、描述符、标识、反应及化学服务 |
| materials/ | 材料数据库、晶体与量化文件、MOF和模拟引擎 |
| biology/ | 序列、结构、描述符及科学服务适配 |
| machine_learning/ | 数理、统计、模型验证、优化与研究计算 |
| general/ | 数据文件、记录操作、检索与受限数值执行 |
| shared/ | 跨工具配置、数据访问、文件和通用科学后端 |
| adapters.py | 既有序列化学、构象与对齐格式适配；具体公开绑定见索引 |

第三方代码和来源许可位于 `resources/external_sources/`。新增能力在对应学科模块实现，完善唯一契约后重建索引；同一核心能力的输入形式与算法选项通过明确参数表达，避免重复的公开入口。共享内核不直接成为工具，只有 catalog 中登记的契约可以公开执行。
