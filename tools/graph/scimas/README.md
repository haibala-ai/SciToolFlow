# SciMas 专属工具知识图谱

该目录由 `python -m baselines.scimas.build_knowledge` 构建。SciMas 的查询运行时仅使用这里的图谱和向量，SciToolAgent 保持使用上一级目录的原图谱。

| 文件 | 内容 |
| --- | --- |
| `annotations.json` | 人工审查的 SciMas 补充知识：端口解释、方法约束、执行提示及来源身份 |
| `graph.json` | 独立的工具—端口—数据概念—约束图，附规划所需的公共契约 |
| `embeddings.json.gz` | 独立保存、按规范工具名索引的功能向量及提供商身份 |
| `manifest.json` | 图谱、工具契约、补充知识、向量的身份与规模 |

当前共 472 个工具、1,755 个端口，包含 99 份绑定当前契约与源码的专门审查记录。所有工具具备契约派生的规划信息；原有 6 份记录提供详细端口和方法约束，97 种本地工具还完成了成对生产进程调用检查，两者有重叠。隔离执行证据见 [parallel_review.json](parallel_review.json)。审查包括矩阵维度、表示边界、本地分子计算及固定 Q-Chem 输出解析；未知成本与未审查的并发性质保持未知。

补充知识只能来源于工具契约、实现、公开方法文档或真实运行测量，不写入题目答案、评分规则或参考路径。修改 `annotations.json` 后需要重建图谱；契约变更使对应的专门审查记录过期，构建器会要求重新核对。算法性能描述与实测延迟分开，不把未经测量的运行时间当作已知成本。

当前功能文本未变化，因此向量从已有索引按文本和模型身份校验后复用，构建未调用 embedding API。新补充知识通过结构化检索与 Planner 上下文使用。具体查询接口、任务图定义及验收见 [SciMas 实现说明](../../../baselines/scimas/README.md)。
