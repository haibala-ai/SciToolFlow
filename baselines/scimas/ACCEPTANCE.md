# SciMas 初次工作流验收（2026-11-04）

本页记录初次验收的冻结版本及旧 Mini 题号；后续新版 Mini 的实现效率验证见[效率与最新抽测](EFFICIENCY.md)。

SciMas 已实现独立工具图谱、任务 DAG、Planner／Executor／Reviewer 协作、事件驱动执行、过程审查和局部修复，并接入项目统一运行与评分入口。下列记录区分工程验证、真实模型样例与历史调试，不把测试替身计作模型实验。

## 三个核心指标

| 最终验收样例 | 运行完成率 | 工具规划准确率 | 答案准确率 |
| --- | ---: | ---: | ---: |
| Mini FLOW-0015：光谱通道选择 | 100%（1/1） | 100%（1/1） | 100%（1/1） |
| 全集 FLOW-0481：重复插补不确定性 | 100%（1/1） | 100%（1/1） | 100%（1/1） |

两题均无语义待复核项，轨迹及资源身份认证均通过。Mini 使用 7 次科学调用、20 次模型请求，全集使用 14 次科学调用、34 次模型请求；均无协议错误或答案格式错误。

在本页历史冻结版本中，这三项对应评分输出的 `pass_rate`、`tool_planning_accuracy` 和 `final_answer_accuracy`。运行完成率检查是否正式提交答案；工具规划准确率检查必要科学能力及其依赖是否得到实际调用支持；答案准确率要求科学结果和所需证据链同时成立，不能用“最终数值相同”替代。

样例用于验证完整工作流，不是 500 题或 200 题的性能估计。此次没有修改题目、参考答案、评分判据或预测中的科学结果，也没有为 SciMas 增加评分例外。

## 测试方法

最终模型为 **GPT-6.1 Terra**。每次模型请求都使用一个全新、`fork_turns=none` 的子智能体，只提供当前角色的公开题目、工具契约、运行历史和响应结构；不提供参考答案、评分器或父智能体的分析。调度子智能体只投递请求，不读取科学内容，也不提供解题提示。科学工具由真实 SciMas 运行时执行。

这是新上下文与访问指令形成的信息隔离，不是操作系统强制文件沙箱。提供方没有暴露 token 用量，账本将其记为未知。调度等待包含外部协调开销，不能据此比较生产 API 的推理速度。

公开附件预览仅用于理解问题。文件中的科学数据必须经过真实读取工具，再绑定到下游节点。角色声明不能伪造读取观测、已确认元数据或缺失字段。完成运行后，另用公开输入独立计算：Mini 用 Gram 矩阵解析特征值核对奇异值和原始矩阵秩，全集按 Rubin 公式核对方差分解、有限插补自由度及独立平均捷径。

工作区存在并行修改，因此最终运行与评分使用冻结的公开源码、任务和工具快照。私有凭据仅供运行时访问，未进入模型上下文或快照归档。Mini 测试请求上限为 40，全集恢复项目默认的 400；两者均保留真实资源账本。

## 工程验证与修复

完整回归 **1,161 项测试、803 项子测试通过**；SciMas 专项 **83 项通过**。依赖库产生 11 条警告，没有测试失败。冻结项目校验通过：500 道全集、200 道 Mini、473 个注册工具和 5,944 份内联参考输出一致。

| 验证对象 | 已验证的行为 |
| --- | --- |
| 规划状态 | 新请求携带已完成检索及剩余额度，不能丢失检索历史并无限重复搜索 |
| 文件数据来源 | 预览支持理解，真实读取与下游绑定形成可核验的执行证据 |
| 动态 JSON | 显式开放的文档字段可先规划访问；执行时仍拒绝缺字段、错误类型和非数组映射 |
| 独立动态映射 | 展开一组映射不改写另一组的 item 绑定；两种展开顺序均有测试 |
| 类型与科学审查 | 输出必须满足工具契约；科学门控须有有效证据，异常不能当作科学否定 |
| 并行与取消 | 独立调用目录、事件驱动推进；取消对应进程组，未知安全性工具在本题内独占运行 |
| 局部修复 | 保留无关有效结果，取消受影响在途调用，陈旧结果不能进入新图 |
| 最终提交 | 公开答案结构反馈、独立审查、仅引用当前已接受的真实观测 |
| 资源与轨迹 | 所有角色共用请求账本，真实调用及失败尝试保留，可通过统一评分入口认证 |

SciMas 图谱包含 472 个工具、1,755 个端口、2,686 个节点和 3,521 条边。动态字段规则修复后已重建专属图谱。SciToolAgent 原图谱、原索引、原基础清单与公共 catalog 哈希保持不变。工具功能描述未改，既有功能向量未重新计算。

历史调试记录保留了附件证据链不匹配、动态字段校验错误、独立映射展开错误、embedding SSL 故障，以及因并行源码修改或临时测试预算而中断的运行。它们不覆盖、不混入最终样例结果；因此本记录不提供多次尝试后的模型性能估计。Reviewer 也不是科学真值，其他未登记的等价路径仍应按统一规则处理，不能给某个方法单独放行。
