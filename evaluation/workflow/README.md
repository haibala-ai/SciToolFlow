# workflow.v1评分实现

此包是当前500题的确定性科学评分器，公开接口由__init__.py导出。它只读取受信观测和已声明判据，不运行提交的代码，不调用科学服务或生成模型。

| 模块 | 职责 |
| --- | --- |
| engine.py | 能力路线搜索、证据落地、整题判定和指标汇总 |
| matching.py | 工具观测匹配、分支条件、能力依赖与重复执行身份 |
| schema.py / schema.json | 工作流规格、表达式操作、选择器与有界结构校验 |
| values.py | 严格类型、数值边界、无序表示、曲线比较与JSON大小界限 |
| expressions.py | 从受信观测、输入和答案解析有界证据表达式与谓词 |
| contracts.py | 工具字段选择器核对及公开答案比较约定 |
| constants.py | 按内容哈希引用的字面量常量 |
| literal_evidence.py | 观测中显式字面量的受限解码 |
| numeric_expression.py | 计算器回执中的封闭算术表达式解码 |
| program_identity.py | 已审查完整 Python 程序的有界语法树身份；接受排版变化，保留全部算法、数据和类型 |

runner.py在评分前调用integrity包验证发布身份和真实轨迹，再调用本包。无法直接判定的方法交给review处理。当前发布只支持 workflow.v1。

科学判据可以声明 `scientific_domains`，用严格的数值上下界限定其答案叶节点。它约束原判据，不增加科学得分项；既有容差只在合法域内生效。该约束随公开比较元信息发布，参考生成身份仍通过原始公开任务记录核验。
